# ReserveME

Gestionale di prenotazioni e appuntamenti per centri estetici, barberie, parrucchieri e centri massaggi.

Il progetto è composto da tre parti:

- `backend/` — API REST (Java 21, Spring Boot, PostgreSQL, Flyway)
- `mobile/` — app per il cliente finale (Expo / React Native)
- `admin-web/` — backoffice web per il gestore del negozio (Vite, React)

Per le istruzioni su come avviare il progetto, vedere [RUNNING.md](./RUNNING.md).

Documentazione di architettura (diagrammi entità-relazione, flussi, specifiche API) in `docs/`.
